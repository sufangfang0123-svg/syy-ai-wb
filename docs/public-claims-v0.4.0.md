# v0.4.0可声明与禁止声明

当前状态：**真实Provider UAT未通过**。现阶段只能声明工程框架、固定评测集、离线fixture测试和人工闭环已完成；不能使用下列“通过后可以声明”的真实AI运行时表述。

## 通过真实Provider UAT后可以声明

- AI可以从用户明确授权的材料中提取带出处的候选Evidence；
- 每条候选Evidence需要人工复核；
- 人工确认后的Evidence可以进入现有可追溯决策链；
- Gate仍由`NDG_GATE_V0.3.0`确定性规则计算；
- 最终Decision仍由负责人确认；
- AI运行和人工修改保存审计轨迹。

## 仍禁止声明

- AI输出就是事实，或模型置信度等于正确概率；
- AI自动判断产品成功、预测爆款、销量、ROI或市场需求；
- 自动全网采集、自动确认Evidence、自动评级或自动关联；
- 自动生成全局最优实验；
- 真实客户成果、云端企业系统、多人权限、可信审批或生产级安全合规。

统一表述：**AI负责把授权材料转化为带出处的候选证据，规则负责计算Gate，负责人决定下一笔投入。**
