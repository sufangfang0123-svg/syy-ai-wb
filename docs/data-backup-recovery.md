# 数据备份与恢复

默认数据根目录为`backend/data/`，包含SQLite数据库和`uploads/`附件快照。正式试点应通过`NDG_DATA_DIR`指向受企业控制、不可公开访问且纳入磁盘备份的目录。

备份：停止`dev:integrated`，复制整个数据根目录，并记录复制时间和SHA-256。恢复：停止服务，保留现有目录副本，将备份整体还原后启动，检查`/api/v1/health`与项目导出。不要只恢复SQLite而遗漏附件。

迁移由启动时的向前迁移执行；schema v1会原位升级到v2并保留v0.2记录。禁止把数据库、附件、导出、UAT数据或测试报告提交到Git。删除项目会按外键删除数据库记录，但附件快照的物理清理仍需试点管理员按保存期限执行。
