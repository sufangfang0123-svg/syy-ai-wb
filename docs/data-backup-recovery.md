# 数据备份与恢复

默认数据根目录为`backend/data/`，包含SQLite数据库和`uploads/`附件快照。正式试点应通过`NDG_DATA_DIR`指向受企业控制、不可公开访问且纳入磁盘备份的目录。

备份：停止`dev:integrated`，复制整个数据根目录，并记录复制时间和SHA-256。恢复：停止服务，保留现有目录副本，将备份整体还原后启动，检查`/api/v1/health`与项目导出。不要只恢复SQLite而遗漏附件。

迁移由启动时的向前迁移执行；schema v1/v2会原位升级到v3并保留既有记录。v3新增AI来源、运行和候选审核轨迹，不改变`NDG_GATE_V0.3.0`。禁止把数据库、附件、导出、UAT数据或测试报告提交到Git。

删除或到期清理必须同时覆盖SQLite中的项目、AI来源/运行/候选、正式Evidence以及`uploads/`物理快照。数据库外键负责项目内记录级联；物理快照仍需试点管理员按材料授权与保存期限清理。当前没有账号、集中保留策略或远程删除服务，因此不要把“删除数据库记录”描述为完整的数据销毁证明。
