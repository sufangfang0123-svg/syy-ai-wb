## 证据使用规则

1. 模拟案例必须显示“模拟夹具”。
2. 系统UAT必须显示“系统验收案例／固定脱敏夹具／非客户成果”。
3. 真实企业数据当前为零；任何客户、访谈、订单、收入、ROI或节省金额都不得加入展示。
4. `NDG_GATE_V0.3.0`是确定性规则版本，不是模型版本。
5. 测试通过只证明代码路径符合断言，不证明市场、产业或经营结果。
