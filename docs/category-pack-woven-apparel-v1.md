# Category Pack：woven_apparel_v1

`woven_apparel_v1`是本地工作台默认启用的有纺服装行业包，版本`1.0.0`。它是字段、检查规则和模板配置，不是市场研究结论。

包内包含：人群、场景、JTBD/痛点、产品基因字段、规格比较维度、供应风险、批准声明、禁用词、验证模板、渠道内容模板、排序维度和缺失输入说明。

默认概念为“全棉轻适通勤内搭（比赛概念方案，非全棉时代正式产品）”。材质成分、克重、缩水、色牢度、价格、起订量、交期、用户需求和功能价值必须由企业技术资料或真实研究验证。没有Evidence时不得把这些字段写成确定事实。

100项候选空间来自4类人群×5类产品基因×5类渠道/场景组合。缺少8项明确输入时`priority=null`并列出缺失项；输入齐全时只计算版本化“待验证优先级”，不输出成功率、销量、CTR/CVR或ROI。

`legacy_nonwoven_cotton_care_v1`保留旧非织造棉品模拟夹具，状态为`legacy`，不是本轮本地默认包。
