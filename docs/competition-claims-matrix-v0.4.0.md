## 固定替换词

| 不得写 | 应写 |
| --- | --- |
| AI自动找到最优产品 | 形成受审候选，由负责人比较和选择 |
| AI推荐Top 12 | 负责人显式选择Shortlist并记录理由 |
| AI智能Gate | 确定性Gate规则 |
| 真实企业成果 | 固定脱敏系统验收或待企业试点 |
| 云端企业版 | 公开模拟演示＋本地封闭试点能力 |
| 已验证业务价值 | 已定义待试点测量指标 |
| 自动生成最优实验 | 记录由负责人设计的验证方案 |
