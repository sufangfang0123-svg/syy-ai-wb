## 完整旁白稿

新品失败往往不是缺少创意，而是在关键证据不足时过早投入下一笔打样、备货或投放费用。Evolution Lab · Next-Dollar Gate不预测爆款，而是帮助团队在下一笔钱发生前排除错误。

系统把责任分成三层：AI生成候选、解释反证和缺失输入；确定性规则校验Schema、引用、stale和固定Gate；人确认事实、筛选候选并承担最终决定。AI不能确认事实，规则不伪装成AI，人工作出的决定也不会反向修改系统建议。

流程从已授权材料开始。材料先成为有原文、来源、适用范围和限制的Evidence。外部AI候选进入AIProposal，保留输入快照、引用和版本，没有人工接受就不是正式机会。Category Pack形成100个情景候选；因为目前没有逐情景可信输入，所以全部未评分，不存在自动Top N。负责人明确选择Shortlist，并记录理由和证据。

被选情景进入产品概念和Validation。负责人锁定一个主变量，预设通过、补证和停止阈值。固定的NDG_GATE_V0.3.0根据合格输入输出建议，最终继续、补证或停止由人确认。

概念继续进入内容资产。每条内容追溯到概念、Evidence和Claim边界；反馈回流为ChangeProposal，不会自动改写旧Gate。上游Evidence变化时，真正依赖它的下游对象会stale并留下Audit，旧结论不会自动复活。

当前公开站只使用固定模拟或脱敏系统验收夹具。Provider请求为零，没有真实客户成果、账号、RBAC、多租户或云生产。下一步不是继续堆功能，而是用一份授权、脱敏企业材料跑一次本地人工POC，测量追溯、复核和风险识别价值。
