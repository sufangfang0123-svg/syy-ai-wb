# AI安全与威胁边界 v0.4.0

- API密钥只由FastAPI进程从服务端环境读取，不进入前端、数据库、Audit、导出、截图、CI或GitHub Pages。
- 每次调用必须由用户主动触发，并受输入字符、候选数量、输出token、项目运行次数、超时和零自动重试限制。
- 模型没有工具，不会跟随材料中的链接。公开URL导入拒绝内网、回环、链路本地、保留地址、非标准端口和URL凭据；每次重定向重新解析并校验，且不继承系统代理环境。
- 文件检查扩展名、MIME、签名、大小、页数、编码、路径字符和DOCX解压预算；快照位于非公开本地目录。
- exact或有限规范化匹配为`VERIFIED`；引用只出现在其他片段时为`NEEDS_MANUAL_VERIFICATION`；不存在时为`INVALID`。不使用宽松模糊匹配。
- `INVALID`不能接受；人工核验项必须显式勾选。AI原始输出不会被人工版本覆盖。
- 测试fixture不使用真实密钥，provider失败不回退fixture，不显示假成功。

当前没有账号、RBAC、多租户、可信身份审计、企业审批、数据防泄漏平台或法律合规认证。人员字段仍是人工自我声明；企业必须自行确认材料授权、脱敏、保存期限、删除要求和所选provider条款。
