# 当前版本风险修复与验收记录

验收日期：2026-08-11

## 结论

本轮报告中的P0问题已完成代码修复并通过指定自动化与多视口复核。当前版本可作为公开演示和企业试点原型交付；它仍是静态前端与浏览器本地存储方案，不应表述为企业生产系统。

## 已修复项目

1. 新手指引改为目标聚光与自适应浮层；第三、四步不会遮住被解释区域。
2. 初始焦点进入指引，Tab与Shift+Tab保持在指引内，Esc可关闭，关闭后焦点回到“新手指引”按钮。
3. 投前决策单新增人工决定确认、必填理由、时间记录、持久化和系统/人工差异提示。
4. 实验状态统一为`待执行`、`进行中`、`已完成`；待执行真人方案不再算作真人校准完成。
5. 无动作的“保存草稿”按钮改为明确的自动保存状态，并通过`aria-live`播报。
6. 新增非交互式ESLint、类型检查、Playwright关键流程测试和GitHub Actions质量工作流。
7. 旧文档中的14个业务路由、已完成像素级验收等不准确表述已更正。
